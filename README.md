# Bitácora SQL

Curso paso a paso de bases de datos con SQL que corre completo en el navegador (SQLite compilado a JavaScript con sql.js).

- 28 lecciones en 7 módulos: fundamentos, LDD, LMD, consultas con SELECT, álgebra relacional, procedimientos almacenados y proyecto final.
- Cada lección tiene tres partes: **Aprende** (ejemplos que se ejecutan), **Comprueba** (quiz) y **Practica** (ejercicios que se corrigen solos).
- La siguiente lección se abre al completar o saltar la actual. El avance se guarda en el navegador.
- Incluye un intérprete de T-SQL para practicar procedimientos almacenados como en SQL Server, el LAB revisado contra sus anexos, pistas del SQL Murder Mystery y un examen final.

`index.html` se genera con `publicar.sh` a partir de `fuente/bitacora-sql.html`.
